# Web Fluid Master Catalog: Working & Theorized Versions

This catalog documents the exact preparation protocols, confirmed working versions, and planned engineering iterations of the sprayable web fluid.

---

## 🏷️ Versioning Standard
- **Major Versions (1.0, 2.0, 3.0...):** Finalized milestone systems or major completed engineering phases.
- **Minor Versions (1.1, 1.2, 1.3...):** Incremental improvements, material changes, ratio optimizations, or solvent adjustments.
- **Status Tags:**
  - `[WORKING]` — Physically prepared, sprayed, and confirmed to form airborne strands.
  - `[ACTIVE FORMULATION]` — Current active development target.
  - `[THEORIZED]` — Formulated by research, ready for future validation.

---

## 📋 Catalog of Versions

### `web-fluid-1.0` [WORKING / RETIRED]
*The Glassy Polymer Baseline (Proof-of-Concept)*

- **Status:** Validated / Retired Baseline
- **Polymer Base:** Polystyrene (Thermocol)
- **Solvent:** Thinner SP-85
- **Result:** Formed airborne webs, but brittle and crumbly ($T_g \approx 100^\circ\text{C}$).

---

### `web-fluid-1.2` [WORKING / COMPLETED]
*The Synthetic Rubber Proof-of-Concept*

- **Status:** Completed Phase
- **Polymer Base:** Fevibond (Synthetic Neoprene Rubber)
- **Solvent:** Thinner SP-85 (40:60 ratio)
- **Result:** Proved that synthetic rubber forms **flexible, non-brittle airborne web strands**.

---

### `web-fluid-1.3` [ACTIVE FORMULATION]
*High-Density Tensile Web System*

- **Status:** Active Development Target
- **Objective:** Transform `1.2`'s thin cobwebs into thick, high-tensile, ropy web strands capable of bridging gaps and supporting physical loads.
- **Polymer Base:** Fevibond Synthetic Neoprene Rubber
- **Solvent:** Thinner SP-85
- **Formulation Specs:**
  - **High-Viscosity Base:** Fevibond dissolved into SP-85 until $40\%\text{–}50\%$ thicker than water.
  - **High-Density Ratios:** 
    - **Option 1.3-A ($50:50$):** $50\%$ Base Concentrate : $50\%$ Thinner SP-85
    - **Option 1.3-B ($60:40$):** $60\%$ Base Concentrate : $40\%$ Thinner SP-85
- **Target Performance:** Double the strand diameter, high pull resistance, fast in-flight flash drying.

---

### `web-fluid-2.0` [THEORIZED]
*The First Finalized High-Strength System*

- **Status:** Milestone Target
- **Criteria for Version 2.0:** A stable, optimized web fluid that consistently bridges a $30\text{ cm}$ gap, dries tack-free in $<2$ seconds, and holds a measurable weight (e.g., small tool, battery, or keys) without breaking.
